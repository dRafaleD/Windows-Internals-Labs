# Day 09 — Windows Event Logs, Providers and Event IDs

[English](notes.md) · [Türkçe](notes.tr.md) · [Practice](lab.py)

## Objective and context

Windows event logs are generated by different providers and channels. An Event ID is meaningful only with provider, version, channel and event fields.

## Technical concepts

1. Security events such as 4624 (successful logon) and 4688 (process creation) may depend on enabled audit policy and event version.

2. Event ordering across systems requires timestamp normalization and awareness of missing events, log rotation and collection delay.

3. A logon event documents a reported authentication outcome; it does not by itself prove interactive human intent.
